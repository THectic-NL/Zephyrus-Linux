# My Setup Notes

Everything I've documented while running Linux on the ROG Zephyrus G16 (GA605WV), for both distributions I'd recommend on it: **CachyOS** and **Bazzite**.

**Start with [Getting Started]({{< relref "/docs/getting-started" >}}) and pick one of the two.** That page is a short, honest recommendation rather than a feature table: CachyOS if you want the machine in your hands, Bazzite if you game or would rather not tinker at all. Everything after it follows from that choice.

Already know which one you're on? Jump to whichever section is relevant. Pages that apply to both use tabs for the commands that differ — pick your distribution once and the rest of the page follows — and the handful of topics that work fundamentally differently have a page each.
